# Front-end operations 前端运维

## Vim 编辑器 (vimtutor  ) `vim tuːtər`

Vim 是一个基于模式的文本编辑器，其核心思想是：**让你的手尽可能留在键盘中心区域，通过指令代替鼠标操作。**

`四大模式`

Vim 的操作在不同模式间切换完成：

| 模式 | 快捷键 | 功能描述 |
| :--- | :--- | :--- |
| **普通模式 (Normal)** | `Esc` | 默认模式。用于移动光标、复制、粘贴、删除、撤销。 |
| **插入模式 (Insert)** | `i` / `a` / `o` | 用于文本输入。 |
| **命令行模式 (Command)** | `:` | 用于执行保存、退出、搜索、设置等全局指令。 |
| **可视模式 (Visual)** | `v` / `Ctrl+v` | 用于选取文本块，类似鼠标拖选。 |

`基础生存指令`

进入与退出
- `i`：在光标前开始插入。
- `a`：在光标后开始插入（append）。
- `o`：在当前行下方新开一行。
- `:w`：保存。
- `:q`：退出（无修改时）。
- `:wq` 或 `ZZ`：保存并退出。
- `:q!`：强制退出，不保存。

光标移动
- `h` `j` `k` `l`：左、下、上、右。
- `w` / `b`：向后 / 向前跳到一个单词的开头。
- `0` / `$`：移动到行首 / 行尾。
- `gg` / `G`：移动到文件开头 / 末尾。
- `:[line]`：跳转到指定行（如 `:20` 跳转到第 20 行）。

删除与剪切
- `x`：删除光标处字符。
- `dw`：删除一个单词 (Delete Word)。
- `dd`：删除（剪切）当前行。
- `d$`：从光标处删除到行尾。

复制与粘贴
- `yy`：复制当前行。
- `p`：在光标后粘贴。
- `P`：在光标前粘贴。

撤销与重做
- `u`：撤销 (Undo)。
- `Ctrl + r`：重做 (Redo)。

为什么 SSH 远程开发离不开 Vim？

1. **零图形依赖**：SSH 登录 Linux 服务器后通常没有 GUI，Vim 是最通用的终端编辑器。
2. **轻量极速**：对于几百兆的日志文件，Vim 的打开速度远超 VS Code。
3. **环境统一**：无论是 AWS、阿里云还是本地服务器，Vim 的操作逻辑永远一致。

`什么是 SSH？` `/sɪˈkjʊr ʃel`

SSH 是 Secure Shell（安全外壳协议） 的缩写，是一种用于在不安全网络中安全地远程登录和操作服务器的加密网络协议。

SSH 使用了多种加密技术：
- 非对称加密（RSA / ED25519）
- 对称加密（AES）
- 哈希校验（防篡改）

两种认证方式
密码登录: `ssh root@1.2.3.4`
SSH Key 登录：`ssh -i ~/.ssh/id_rsa user@ip`

`Linux 权限 666 规则要点`

默认权限
- **文件最大起点**：666 (`rw-rw-rw-`)。系统默认不赋予新文件可执行权限。
- **目录最大起点**：777 (`rwxrwxrwx`)。目录需要 `x` 权限才能被 `cd` 访问。

umask 对权限制约
- 系统通过 `umask` 命令查看掩码（通常是 `022`）。
- **计算逻辑**：
  - 文件：`666 & (~umask)`。简单理解为从 666 中剔除 umask 指定的权限。
  - 示例：若 `umask` 为 `022`，新文件权限为 `644` (所有者读写，组/其他人只读)。

权限掩码（umask） 是 Linux/Unix 系统中的一个内置安全机制。它的作用是限制新创建文件或目录的默认权限，确保系统资源在生成时不会因权限过大而产生安全漏洞。

```bash
chmod 777 filename  # 赋予所有人读、写、执行权限（慎用！）
chmod 666 filename  # 赋予所有人读、写权限
```

`shell`

Shell 是一种命令行解释器，它为用户提供了一个交互式接口，用于解释并执行用户输入的命令，从而间接调用操作系统内核提供的系统调用来运行程序和管理系统资源。

echo: 输出命令行参数
alias: 定义命令的别名 alias ls='ls -l'（临时） alias ls='ls -l' >> ~/.bashrc（持久）

`快捷键`
`Ctrl + C`：终止当前命令。
`Ctrl + L`：清屏。
`Ctrl + A`：将光标移动到行首。
`Ctrl + E`：将光标移动到行尾。
`Ctrl + U`：删除光标前的所有字符。

 history: 显示命令历史  -c 清空历史 -w 写入历史(默认退出会写)

命令：
`wc file`: 统计行数、单词数、字节数。

管道命令：多命令顺序执行

`;`：多个命令执行，之间没有任何逻辑联系。
`&&`：当前者执行成功，后者才执行。
`||`：当前者执行不成功，后者才执行。

管道符号：`|` 前者的输出作为后者的输入。

`变量`：
定义变量：name=value 字符串
输出变量：echo $name
查看变量：set
删除变量：unset name

`环境变量`：当前shell 有效
定义环境变量：export name=value   declare -x name=vale 导出环境变量
输出环境变量：echo $name
查看环境变量：printenv
`PATH`：环境变量，用于指定可执行文件的搜索路径。

`预定义变量`
$?: 命令执行状态码 0 表示成功 非0 表示失败
$$: 进程ID

系统环境变量文件：
/etc/profile: 系统环境变量文件 针对 所有 shell
/etc/bashrc: bash 环境变量文件 针对 bash
~/.bash_profile: 用户环境变量文件
~/.bashrc: 用户环境变量文件
