公司去年开始组织架构调整，管理层和技术负责人都发生了比较大的变动，团队方向也重新调整了。
我原来主要负责的方向和新的团队规划匹配度没那么高，所以我现在也希望找一个更长期、技术方向更一致的平台。属于组织调整下的人员优化。

[第一部分]“面试官您好，我叫冯剑。非常高兴今天能有这个机会跟您交流。我拥有 9 年的前端全栈开发与团队管理经验，技术栈核心深耕在 Vue 3、TypeScript 和 Node.js（NestJS）BFF 架构体系。同时，我也有着退役军人的背景，这培养了我极强的抗压能力、自驱力以及对结果负责的执行力。”

[第二部分）]“在我的职业生涯中，我的工作核心主要围绕**‘大规模复杂业务交付’和‘企业级研发效能基建’**两条主线：在业务架构方面，我曾主导过大型分布式大宗能源 SaaS 平台的架构重构。针对业务群割裂、高并发鉴权复杂的痛点，我采用分布式架构进行解耦，将系统耦合度降低了 70%。

同时，在后端利用 NestJS 落地 BFF 层，在内网聚合裁剪并发请求，

我曾自研基于 Node.js、TS 和 AST 抽象语法树的接口与权限自动收集平台，实现了接口 100% 准确同步，彻底告别了人工配置的低效。

近一两年来，我深入紧跟前沿的 Rustify 基建（如 OXC、Rolldown）以及 AI 落地。

在团队内，我主导推行了一套基于项目本位的 AI 智能化研发基础设施。通过 Prompt as Code 规范提示词资产，利用 LlamaIndex.ts 和 MCP 协议 将团队私有组件库与 Apifox 字典语义化注入 IDE 端侧。这套基建让团队的 AI 代码采纳率达到了 45% 以上，规范类低级 Bug 减少了 80%，显著缩短了新员工的上手周期。”

[第三部分）]“9 年的沉淀让我不仅能够在一线解决极其刁钻的工程技术边界问题，同时也具备带领团队、用技术手段为业务降本增效的负责人思维

。我看了一下咱们团队招募的这个岗位，对前端工程化深度、业务全栈交付能力以及前沿技术敏锐度都有很高的要求，这跟我的能力模型和技术追求是非常契合的。以上是我的简单介绍，谢谢您！”
