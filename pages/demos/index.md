## 离职原因
公司去年开始组织架构调整，管理层和技术负责人都发生了比较大的变动，团队方向也重新调整了。
我原来主要负责的方向和新的团队规划匹配度没那么高，所以我现在也希望找一个更长期、技术方向更一致的平台。属于组织调整下的人员优化。

## 自我介绍
面试官您好，我叫冯剑，9 年前端开发经验，近几年负责前端架构与团队交付，技术栈以 Vue 3、TypeScript 为主，并在 Node.js / NestJS 上落地过 BFF。

我过去的工作主要围绕两条主线：

第一是复杂业务平台的稳定交付，我参与并推动过大宗能源供应链 SaaS 的多业务子系统建设与统一认证体系落地（SSO/权限模型/跨系统登录态），保障多团队协作下的持续迭代。

第二是企业级研发效能基建，我主导过前端技术栈从 Angular 到 Vue 3 的迁移与规范化，沉淀统一模板、工程规范与 CI/CD 流程，整体研发效率提升约 30%。

近一两年我重点做 AI 工程化落地：通过 Prompt as Code、.agents 上下文注入和工作流 SOP，把团队规则、接口契约与私有组件库能力固化到 IDE 侧，团队 AI 代码采纳率提升到 45%+，规范类低级问题减少约 80%，同时显著降低新人上手成本。

我希望应聘的岗位是高级前端/负责人方向，能在一线解决工程边界问题，也能把规范、基建和协作机制做成团队的长期收益。谢谢。
