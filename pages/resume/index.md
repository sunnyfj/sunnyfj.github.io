#### 核心项目：

##### 大宗能源（煤炭）供应链全链路 SaaS 平台

- 项目角色：前端技术负责人 / 核心架构师（主导）
- 技术栈：Vue 3、TypeScript、Vite、Pinia、Vue Router、Element Plus、Tailwind CSS、Aliyun OSS、Axios

项目描述

该平台是公司核心的分布式大宗能源供应链 SaaS 系统，涵盖煤炭贸易、采购、销售、物流运输、品控质检、财务结算等 6 大核心业务域，支撑高频、大额的大宗交易履约。
项目采用“主应用导航拓扑 + 核心业务子系统集群”的分布式架构，各子系统作为独立项目进行开发并配置独立的 CI/CD 部署流水线。通过主导构建统一单点登录（SSO）鉴权互信、私有化公共组件库等标准治理体系，解决了大规模 B 端应用群的权限割裂、代码复用难、跨域鉴权复杂等痛点。

核心职责与技术亮点
1. 架构设计与工程化解耦（多项目分布式集群）

- 多系统独立自治方案：结合业务解耦需求，主导 6 大子系统的独立工程化搭建。摒弃沉重的单体结构，采用子系统独立版本控制与独立发布流水线（CI/CD），实现各业务线的并行开发与敏捷部署，系统间耦合度降低 70%。

- 私有化公共组件库建设：基于 Vue 3 + TypeScript 提炼并封装了契合供应链业务场景的高阶公共业务组件群（如大宗商品多级地址选择器、合同动态审批流、财务对账单、品控状态看板等），通过标准的 npm 依赖治理，使新业务页面平均开发周期缩短 30%。

2. 身份认证与跨应用安全鉴权体系（SSO 互信）

- 全链路凭证托管与无感刷新：设计并实现了基于主应用的 SSO 单点登录与跨域名凭证分发方案。用户一次登录即可通行所有子系统。

- 高可用鉴权拦截器：统一封装 Axios 网络层，实现双 Token 无感刷新机制。子应用感知 Token 临期失效时自动拦截并发请求并完成无感刷新；若 Token 彻底失效，则安全引导至单点登录中心重新认证，保障长单据填写、大额财务确认等高频操作的用户体验。

3. 复杂大宗业务场景与核心功能攻关

- 多维度业务矩阵开发：主导了物流系统（运费管理、动态违约）与财务系统（多级付款单流转：财务/领导/出纳三级确认）的架构设计。采用状态机模式梳理复杂的货款与运费单据逻辑，规避了高并发场景下的单据状态冲突。

- 高安全性大附件云端直传：针对合同及品控化验单等敏感资料的上传需求，主导开发了基于 Aliyun OSS 的公共上传组件。支持公私有权限隔离、分片上传与断点续传，配合后端实现 STS 临时 Token 自动定时刷新机制，保障大宗交易资产的上传安全与稳定性。

4. 性能优化与构建调优

- Vite 构建调优与极致首屏：实施高效的 Code Splitting（代码分包策略）、公共依赖（Element Plus 等）按需引入与 CDN 留白。在多域名跳转切换时，各子应用首屏关键加载时间（FCP）控制在 1.5s 以内。

项目业绩 / 价值产出

- 敏捷交付：公共组件库与基础设施落地，减少了 50% 以上的重复轮子编写，显著提升团队整体人效。
- 平稳运行：全链路跨域鉴权与无感 Token 刷新方案上线后，因鉴权失效导致的 B 端用户操作中断投诉率降至 0。
